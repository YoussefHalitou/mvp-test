Dies ist eine Beispiel-Website. Das Chatbot-Widget wird automatisch unten rechts angezeigt.

So bindest du das Widget ein:

<!-- Option 1: Einfach (Standard-Konfiguration) -->
<script src="http://37.27.12.97/widget.js"></script>
<!-- Option 2: Mit eigener Konfiguration -->
<script>
  window.ChatbotConfig = {
    backendUrl: 'http://37.27.12.97:8000',
    apiKey: 'dein-api-key'
  };
</script>
<script src="http://37.27.12.97/widget.js"></script>
